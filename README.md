# 🛡️ SecureScan – Web Security Scanner

SecureScan is a full-stack web application security scanner that analyzes websites for security issues and generates detailed security reports. It consists of a React frontend and a Node.js + Express backend with MySQL for secure authentication, scan history management, and report generation.

## 🚀 Features

* 🔐 User Registration & Login (JWT Authentication)
* 🌐 Website Security Scanning
* 📊 Security Score Analysis
* 🟢 Safe / 🟡 Suspicious / 🔴 Malicious Classification
* 📋 Scan History
* 📄 Downloadable Security Reports
* 🛡️ Secure REST API
* 📱 Responsive User Interface

## 🛠️ Tech Stack

### Frontend

### Backend

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/skramya0512-lgtm/SecureScan-Web-Security-Scanner.git
```

### Backend

```bash
cd securescan
npm install
npm start
```

### Frontend

```bash
cd securescan-frontend
npm install
npm run dev
```
